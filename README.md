# Allan's 隨意畫流程圖

| | |
| --- | --- |
| 工具名稱 | Allan's 隨意畫流程圖 |
| 系統設計 | Allan Lo，https://www.123hi.org |
| 開發日期 | 2026/11/21 |
| 最新版本 | Allanlo-20261122-04 |

類似 Visio 的瀏覽器繪圖工具，重點是**甬道圖、流程圖、心智圖、組織圖**，以及讓圖能**輕鬆放進 Word / PowerPoint 並持續維護**。

- 純前端、免安裝、免建置：直接用瀏覽器開啟 `index.html` 即可（建議 Chrome / Edge）。
- 除了「圖檔轉換」的自動模式（見下）之外，所有資料只在本機瀏覽器處理，不會上傳到任何伺服器。

## 功能

| 類別 | 說明 |
| --- | --- |
| 流程圖 | 處理、判斷、開始/結束、文件、資料、資料庫、子流程、註解…等 16 種圖形；連接線會黏著圖形，搬移時自動跟隨 |
| 甬道圖 | 水平 / 垂直甬道，可增減泳道、拖曳調整泳道大小；搬移甬道時內部圖形一起移動 |
| 心智圖 | `Tab` 新增子主題、`Enter` 新增同層主題，自動排版 |
| 組織圖 | `Tab` 新增下屬、`Enter` 新增同層，由上往下自動排版、直角連線；支援幕僚位置與虛線協調關係 |
| 常用圖示 | 使用者、群組、電腦、筆電、行動裝置、主機、資料庫、雲端、網際網路、防火牆、路由器、交換器、印表機、檔案、資料夾、郵件、鎖 |
| 編輯 | 復原/重做、複製貼上、對齊與等距、填色/線條/文字樣式、縮放平移、自動儲存（瀏覽器本機） |

## 放進 Word / PowerPoint 並保持可修改

| 做法 | 適用 | 之後怎麼改 |
| --- | --- | --- |
| **匯出 PowerPoint** | 簡報 | 匯出的是 PowerPoint **原生圖案與接點**，直接在 PowerPoint 內改字、改色、搬移（接點會跟著走）；也可複製貼到 Word |
| **匯出 Word** | 文件（程序書、報告） | 圖案放在 Word「繪圖畫布」中，都是 **Word 原生圖案與接點**，直接在 Word 內改字、改色、搬移；過寬的圖自動改橫式頁面或等比例縮小 |
| **匯出 Word（圖片）**／儲存 SVG 後插入圖片 | 需要版面最穩定時 | 用本工具「開啟…」直接選那份 `.docx` / `.pptx` → 修改 → 按「存回」，文件其餘內容不變 |
| 複製圖片 / PNG | 快速貼上 | 點陣圖，無法再編輯 |

「儲存」產生的 SVG 內嵌了完整的可編輯資料，因此同一個檔案既是可插入文件的向量圖，也是本工具的原始檔。

## 把現成的流程圖圖檔變成可編輯

按「圖檔轉換…」選圖檔（PNG / JPG 等），或把圖檔拖進畫布，或直接 `Ctrl+V` 貼上截圖。工具請 AI 視覺模型辨識圖形、文字、連接線與甬道，再依原位置重繪成可編輯的圖；完成後左下角顯示原圖供對照。

| 方式 | 需要 | 資料流向 |
| --- | --- | --- |
| 自動 | Claude API 金鑰 | **圖檔由瀏覽器直接傳到 Anthropic API**；金鑰預設只保留到分頁關閉 |
| 手動 | 任何可看圖的 AI 對話 | 複製提示詞＋圖到 AI 對話，把回覆的 JSON 貼回工具 |

辨識結果可能漏字或漏線，轉換後請對照原圖檢查。

## 已知限制

- 需要繞行的連接線（例如從圖形背面折回）匯出到 PowerPoint / Word 時為手繪多邊形，外觀相同但不會黏著圖形。
- 目前為單一頁面；圖形尚不支援旋轉。
- Office 匯出結果以 LibreOffice 驗證過；Word 往返編輯需 Word 2016 以上（支援 SVG 圖片的版本）。
